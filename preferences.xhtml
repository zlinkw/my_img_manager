框选保存是唯一常规采集方式；高级原图提取收在下方。图片只写入唯一外部 SQLite 原图库，不创建 Zotero HTML 预览附件或缩略图。每次打开都会重新读取当前设置并修复异常值。设置修改后自动保存，无需另点确认。 采集方式 默认预览质量影响保存的预览尺寸，不改变原始 PDF。 确认窗口初始类别选“自动判断”时先读图注，再参考正文引用；选择具体类别时直接预填，保存前仍可修改。 避免重复保存同时检查本次会话和外部图片库建议保持开启，避免相同页面区域反复写入外部图片库。 高级原图提取（可选）常规采集无需配置 框选、外部图片库和 PPT 连接均使用插件内置的 Zotero/PDF.js 运行环境，安装后可直接使用，无需 Python、Conda 或联网。本区仅用于从 PDF 额外提取原始嵌入图片，需要 Python 与 PyMuPDF。 最小原图面积比例（占页面）助手会跳过占页面比例过小的嵌入图片，减少图标和噪声；0.01 表示页面面积的 1%。 每页最多原图数限制单页从 PDF 提取的原始图片数量。 每篇最多原图数限制整篇文献的提取总数。 超时（秒）助手超过该时间会停止；不影响已保存的预览。 Python 路径（高级）选择 python.exe…常规功能无需填写。仅高级原图提取的自动查找失败时使用；点击按钮会打开文件资源管理器。可选择 Conda 环境中的 python.exe。
